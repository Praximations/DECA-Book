How to use

Click anything on a page to select it. Double-click text to edit it in place; Enter saves, Esc cancels.

Edits are written straight into src/pages. Saving a file in VS Code refreshes the preview too.
Nothing selected. Click an element on a page.
Classes come from src/styles/components.css. Prefer a class over an inline style when one exists.
These fill the {{placeholders}} on the title page and elsewhere. Lists: one item per line.
Every colour, font and size the book uses, from src/styles/tokens.css. Changes preview live.
The condensed PDF uses smaller photos; use it if the full one gets near the MB limit.
